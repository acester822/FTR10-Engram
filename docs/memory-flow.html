Engram — Memory Flow

write → store → recall → score → gap → enrich → integrity → governance → coherence → audit · matches docs/memory-flow.md (v4.7.x)

Write gates

  • Cooldown 30s — skip or extract
  • Specifics-or-nothing + single-clause (extraction)
  • Malformed → extraction_candidates → processor
  • Dedup: token-overlap NOOP · >0.92 supersede · 0.85–0.92 edge
  • Embed (nomic) + metadata.context + audit row

Judge & scoring

  • Qwen3.6-28B-REAP20 · independent judge
  • recall → {relevance, coverage} · ingest → extraction_fidelity (stored-rubric) · chat → answer_quality
  • Correctness filters in report; excluded_scores reported
  • Catch-up scorer retries judge failures

Human-in-the-loop

  • Apply = human approval → performs the deferred repair (audited, via: user-apply)
  • Dismiss = final, never re-proposed
  • Undo restores full before_state incl. embedding
  • Calibration gate: closed → Tier-2 mutations suspended
